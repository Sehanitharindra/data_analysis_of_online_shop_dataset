# Online Shop 2024 - Exploratory Data Analysis with PostgreSQL

This repository contains an exploratory data analysis (EDA) project using **PostgreSQL**. The analysis is based on the dataset titled [Online Shop 2024](https://www.kaggle.com/datasets/marthadimgba/online-shop-2024), available on Kaggle. The dataset provides transaction and product-related data from an online store, enabling various insights through SQL queries.

## 📊 Analysis Overview

The following analyses are included in this repository:

- 🔄 **Customers who ordered at least 2 products during the last 3 months of 2024**
- 💳 **Count of orders by payment status** (Completed, Failed, Pending)
- 📦 **List of products ordered by each customer**
- 🌟 **Top 20 highest-rated products**
- 💰 **Total cost of orders placed by each customer**

## 📁 Repository Contents

- `sql/` — SQL scripts for each analysis
- `data/` — CSV files containing query results
- `README.md` — Project overview

## 🛠️ Technologies Used

- **PostgreSQL** for database queries
- **CSV** for data storage and sharing
- **Kaggle** as the data source
